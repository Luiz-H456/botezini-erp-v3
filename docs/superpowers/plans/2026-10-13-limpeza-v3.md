### Task 1: `parseBRL` lê "1.000" como milhar

**Files:**
- Modify: `src/utils/currency.ts`
- Create: `src/utils/currency.test.ts`

- [ ] **Step 1: Teste que falha.** Crie `src/utils/currency.test.ts`:

```ts
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { parseBRL } from './currency.ts';

test('ponto com grupos de 3 dígitos e sem vírgula é milhar', () => {
    assert.equal(parseBRL('1.000'), 1000);
    assert.equal(parseBRL('2.500'), 2500);
    assert.equal(parseBRL('1.234.567'), 1234567);
    assert.equal(parseBRL('-1.000'), -1000);
});

test('o resto continua como era', () => {
    assert.equal(parseBRL('0.500'), 0.5);
    assert.equal(parseBRL('1.5'), 1.5);
    assert.equal(parseBRL('12.50'), 12.5);
    assert.equal(parseBRL('1,5'), 1.5);
    assert.equal(parseBRL('1.000,50'), 1000.5);
    assert.equal(parseBRL('1,000.50'), 1000.5);
    assert.equal(parseBRL('R$ 2.345,67'), 2345.67);
    assert.equal(parseBRL(''), 0);
    assert.equal(parseBRL(null), 0);
    assert.equal(parseBRL(42), 42);
});
```

- [ ] **Step 2: Ver falhar.** Com a regra de hoje, "1.000" dá 1.

- [ ] **Step 3: Implementar.** Em `parseBRL`, logo depois de `if (!cleaned) return 0;`:

```ts
    // "1.000" e "2.500" (ponto com grupos de 3 e sem vírgula) são milhar no Brasil.
    // "0.500" e "1.5" continuam decimais: grupo começando em 0, ou de 1–2 dígitos, não é milhar.
    if (/^-?[1-9]\d{0,2}(\.\d{3})+$/.test(cleaned)) return Number(cleaned.replace(/\./g, ''));
```

- [ ] **Step 4: Ver passar.** Rode a suíte inteira, porque `parseBRL` tem 12 usos.
- [ ] **Step 5: Commit.** Mensagem: `fix(numeros): "1.000" é mil, não um`.
