# Agent Rules

Antes de implementar qualquer mudança no projeto:

1. Leia `docs/APP_ARCHITECTURE.md` para entender o todo.
2. Respeite a arquitetura existente descrita no documento.
3. Não crie novas estruturas ou padrões (libs, bibliotecas, routers diferentes) sem verificar os padrões atuais consolidados no código.

Após qualquer alteração estrutural (novas APIs, novas tabelas, mudanças de fluxo):

- Atualize `docs/APP_ARCHITECTURE.md` para manter a documentação viva.
- Atualize as seções relevantes **apenas**.
- **Nunca** recrie o arquivo inteiro do zero.

Objetivo: Manter a documentação sempre sincronizada com o código.
