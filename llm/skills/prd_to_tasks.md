# Skill: PRD to Tasks

**Description:**
Converts a Product Requirements Document (PRD) into an actionable Epic, Stories, and technical Tasks.

**Instructions:**
1. Read the provided PRD or feature request.
2. Break down the requirements into a structured Hierarchy:
   - **Epic**: The high-level goal.
   - **Stories**: User-centric features (e.g., "As a user, I want to...").
   - **Tasks**: Technical changes needed (Frontend, Backend, DB, Docs).
3. Ensure tasks align with the `docs/APP_ARCHITECTURE.md`.
4. Check for edge cases, error handling, and security implications (RLS).
5. Output a structured Markdown checklist to be saved as `task.md` or presented to the user.
